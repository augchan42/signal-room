# Signal Room

Signal Room is the repository for `Synthwave`, a native Android K-pop agency management game.

Development is proceeding from the [Synthwave concept brief](docs/superpowers/specs/2026-09-22-synthwave-concept-brief.md). [The Garden](docs/superpowers/specs/2026-09-22-the-garden-android-scaffold-design.md) is an earlier, separate concept retained for reference.

The current milestone is an offline, deterministic producer demo. See the [producer demo build guide](docs/producer-demo-build.md) for local requirements and verification commands.
